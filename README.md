iRAS 是一个面向**水产养殖工程师、设计院、高校研究者**的循环水养殖系统(Recirculating Aquaculture System)工程设计开源工具。覆盖**工艺设计 → 碳酸盐平衡水化学 → P&ID 工艺图 → 设备清单 → 投资财务评价 → 16 章可研报告生成**的完整工作流。

🌐 **在线使用**:https://iras.cn

### v1.9.1:液氧口径修正 + 蒸发系数量纲修正

与英文版 v2.0 同步的两处物理/口径修正。**不改变设备选型结果**,仅修正消耗品采购量与蒸发潜热。

- **液氧消耗口径修正** — 旧版用含选型余量的 `o2Demand`(含 `peakFactor` × `sAerator`)计算液氧 OPEX 与基准值。液氧是**按量计费的消耗品**,只有吸收效率应放大采购量,容量系数不应参与。新增并行口径 `o2ConsumptionDaily` / `o2ConsumptionDailyAvg`,`o2Demand` 原样保留给设备选型
  - 液氧成本:**高估 65% → 修正**(旧/新 = 1.5 × 1.10 = 1.65)
  - 鲑鱼成鱼液氧基准值:0.44 → **0.266** kg O₂/kg 饲料(文献 0.25–0.30)
  - 液氧年耗(1000 t/yr, FCR 1.2):527 t → **319 t**
  - 液氧储罐(7 天储备):10.1 t → **6.1 t**
  - 验收区间由 0.25–0.95 收紧为 **0.20–0.45**(旧区间是为迁就被膨胀数值而放宽的)
- **蒸发系数 β 量纲修正** — 旧版注释声称 β 取自 ASHRAE Applications Ch.6 的 0.045–0.075 m/s,**这是错误出处**。ASHRAE / Carrier 的池面蒸发系数是定义在**蒸气压差**上的英制系数 [lb/(h·ft²·inHg)],不能直接当作 ΔW × ρ_air 形式的 β [m/s] 使用,否则高估约一个数量级
  - 改用 Lewis 传热传质类比导出:`β = h_c / (ρ·c_p·Le^(2/3))`,β ≈ **0.0035–0.010 m/s**(旧 0.045–0.15)
  - 交叉验证:把 ASHRAE 的 0.089 换算到湿度比基准,同样得到 β ≈ 0.005 m/s
  - 实测效果:蒸发率降 2–2.4 倍(非 13 倍,因 `W_room` 自洽求解存在自补偿);**车间湿度饱和 (RH=99%) 告警消失**

> **回归验证**:`o2PeakSupplyKgH` 与 `o2Demand` 计算式**逐字未变** — 本次改的是"买多少氧",不是"配多大设备",氧锥流量与设备规格与 v1.9 完全一致。

依据详见 `VALIDATION.md` §2(蒸发系数)与 §3(液氧口径)。

### v1.9.2 (第一批):通风量口径修正 + 机械除湿机

热平衡模型的通风量口径修正,并新增机械除湿机建模。**不改变设备选型逻辑**。

- **通风量口径修正** — 旧版通风量 = `ACH × 车间体积`,而车间面积由 `1.6 × 水面积` 自动估算、水面积 = 水体/池深。结果:**养殖密度降低 → 水体↑ → 车间↑ → 通风↑ → 湿热气候下凝结放热↑ → 制冷装机暴涨**,但鱼的数量没变,新风需求本不该变
  - 新口径:`新风量 = max(ACH × 车间体积, 鱼载荷 CO₂ 稀释需求)`
  - CO₂ 需求依据文献 500 g CO₂/kg 饲料(大西洋鲑 409 Terjesen 2013 / smolt 550 Vinci 2004 / 鳗鲡 536 Heinsbroek 1990)
  - 新增可调参数:**车间 CO₂ 限值**(默认 1500 ppm)、**脱气塔尾气入室比例**(默认 0.2)
  - **ACH 默认值 1.0 有了标准依据** — 泳池馆新风标准 0.48 CFM/ft² 湿面积换算,本模型几何下约 0.9–1.5 ACH
  - **除湿不计入新风**:湿热气候通风不能除湿(室外空气比车间更湿),干冷气候靠通风除湿仅需约 0.14 ACH — 两种情况下除湿都不是通风量的决定项
- **新增机械除湿机建模** — 湿热气候养冷水鱼时通常必配(室外更湿,通风无法除湿)
  - 开启后车间湿度被控制在目标 RH,水面凝结减少 → 制冷负荷下降
  - 计算除湿量(kg/d)、除湿机电耗(kWh/d,按 SMER)、冷凝水回收(可抵扣补水)
  - 参数:开关 / 目标 RH(默认 70%)/ SMER(默认 2.5 kg·kWh⁻¹)/ 冷凝水回收
  - 海南夏工况实测:开除湿机后车间 RH 由 92% 降至 70%,凝结放热 2152 → 1222 kWh/d,除湿机电耗 1365 kWh/d,冷凝水回收 3.4 t/d

> **工程意义**:总电耗相近,但车间湿度从 92% 降到 70% — 配除湿机的真实理由不是省电,而是避免霉菌、设备腐蚀与电气故障。

### v1.9.2 (第二批):泵功率口径 + 耗氧-产热绑定 + 成本模型两层化 ⭐ 最新

在第一批基础上继续修正物理口径,并把成本模型从「工艺运行成本」扩到「企业全成本」。**设备选型逻辑仍不变**(7 项 × 4 阶段回归逐位一致)。

**物理口径修正**

- **泵功率口径 —— 轴功率 vs 电功率** — `shaftKw = 9.81QH/(3600η)` 是**轴功率**,不含电机效率。旧实现 (1) 把它直接当电耗计费,漏算电机损失;(2) 用 `pumpHeatRatio = 0.85` 把 15% 轴功率送进车间空气 —— 那是把「电机效率 85%」错记在轴功率上,而电机损失根本不在这个数里
  - 新增 `motorEta`(默认 0.95),电耗 = 轴功率 / motorEta
  - `pumpHeatRatio` 0.85 → **0.97**;空气得热 = 轴功率 × (1/motorEta − pumpHeatRatio)
  - **车间得热原高估约 2.8 倍** → 导致 T_room 顶穿物理钳位、RH 被人为压低到除湿机永不触发
- **T_room 钳位不再静默截断** — 钳位触发时报出未闭合能量缺口。修正泵口径后钳位触发率由 30% 降至 8%
- **代谢产热改由耗氧导出** — 旧式 Schrama 系数 106 kJ/(d·kg^0.85) 源自**饱食投喂**实测且公式无投饵率变量,套商业投饵率高估约 3 倍(1.11 W/kg vs 维持代谢基准 0.11)。改为 `池内耗氧 × 13.6 kJ/g O₂`(Brett & Groves 1979),**11030 → 4053 kWh/d**
  - 同一代谢过程同时决定耗氧与产热,由氧热当量刚性绑定,不再各取各的文献值
- **池内耗氧新增 TSS 依赖项** — 悬浮固体上附着的异养菌在**池内**直接耗氧,同样要靠氧锥供给
  - **固体管理首次与液氧账单挂钩**:微滤机去除率 90% → 40%,池内 TSS 3.0 → 5.0,液氧年耗 **334 → 481 t (+44%)**
- **总溶解气压 (TGP) 成为模型量** — `TGP = 100 + (饱和度 − 1) × 20.95`,阈值鱼苗 110% / 其他 115%,接入 DO 告警

**默认值修正**

| 参数 | 原 | 新 | 理由 |
|---|---|---|---|
| `mainPumpHead_m` | 12 | **7** | 12 是「多级跌落」档,与工具自身提示的「重力回流 5-8」矛盾 |
| `mainPumpEta` | 68 | **75** | 大流量低扬程工况选轴流/混流泵 |
| 支路泵扬程 | 10 | **7** | 支路流量小、管路短,不应高于主泵 |
| `o2SatTarget` | 各鱼种 110-165 | **统一 165** | DO 包线体检发现 5 个阶段击穿、4 个临界 |
| 苗种期饱和度微调 | +5 | **−20** | 原方向与气泡病风险相反 —— 鱼苗最敏感却配得最高 |

比电耗 17.9 → **12.0 kWh/kg**。

**审计发现并修复的 Bug**

- 除湿机电耗未计入 OPEX —— 开除湿机反而降成本,物理上不成立
- 除湿机无 CAPEX、不进设备清单
- `dehumCondRecovery` 断链 —— 有默认值有用途,但无 UI / 无载入 / 无监听
- v1.9.2 第一批的全部新输出(除湿量/电耗/排热/等效 ACH)算了但没有界面出口
- 一处与 v1.9.1 修正自相矛盾的陈旧注释

**DO 击穿告警改为按约束诊断**

旧文案建议「提高循环倍数或 DO 目标饱和度」。统一到 165% 后,「提高饱和度」已成为**危险建议**(会撞进刚规避的气泡病风险)。改为逐条计算四条出路的当前值、所需值与卡点:降密度 / 提 turnover(>6 次/h 标注为工程上做不到)/ 提饱和度(超 TGP 阈值则标红劝阻)/ 改善固体管理。

**成本模型两层化**

```
工艺运行成本 = 饲料 + 工艺电耗 + 工艺消耗品 + 维护 + 保险 + 补水 + 排污 + 折旧
企业全成本   = 工艺运行成本 + 苗种 + 人工 + 管理费
```

新增 7 个成本项、11 个可调参数(维护费率与基数 / 保险费率 / 管理费率 / 劳动生产率 / 人均年成本 / 最小班组 / 补水淡海水单价 / 排污单价 / 苗种单价)。

**分两层输出**的理由:工艺侧每一项都能追到物理量与公式;企业侧本质是经济估算。混进一个总数会拉低整个模型的可追溯性。

> 与 Nordic Aqua(宁波象山)2025 年报对标发现,旧口径比商业实绩低约 38%,差额几乎全在「其他 OPEX」—— 缺的是维护、保险、补水、排污这批项目,不是物理算错了。详见技术手册 21.5。

| mandarin (鳜鱼) | 200t | 淡水 | 50.15 | 61.56 | 7.57 | 11.5 | 淡水 |
| shrimp (对虾) | 100t | 15‰ | 38.66 | 55.15 | 7.23 | 4.6 | 0.89 |

**两个口径的区别**:工艺运行成本含饲料 + 工艺电耗 + 工艺消耗品 + 维护 + 保险 + 补水 + 排污 + 折旧;
企业全成本再加苗种 + 人工 + 管理费。两者**均不含**包装/物流/加工、疫苗药物、顾问技术服务费。

**⚠ 鳗鲡参数已按国际 RAS 产业数据整体重做 (v1.9.2)**

| 参数 | 旧值 | 新值 | 依据 |
|---|---|---|---|
| 养成期密度 | 40 kg/m³ | **120** | 欧洲 RAS「120 kg/m³ 不罕见」，50 g 入池后可达 100–150 |
| 上市规格 | 200 g (5P) | **300 g (3P)** | 3P 美洲鳗批发 92 元/kg，美洲鳗为国内主养品种 |
| 换水率 (养成) | 4%/d | **6%** | 国际 RAS 5–8%/日 |
| 周期 | 12 月 | **15 月** | 单尾生长期 10–14 月至商品规格 |
| 苗种单价 | — | **10 元/尾** | 美洲鳗；缅因州玻璃鳗配额独立反推 10.8 元/尾 |

密度是主因：旧值低 3 倍 → 水体大 3 倍 → 系统与折旧高 3 倍。修正后工艺运行成本由 67.4 降至 **47.7 元/kg**。

**苗种成本 44.4 元/kg**（4.44 尾/kg × 10 元），占企业全成本 43%，接近行业经验的 50%。
鳗苗**全部依赖野生捕捞、无人工繁育**，品种价差极大：日本鳗 15–25 元/尾（歉收年 40+）、
美洲鳗 5–14、花鳗/鲈鳗 3.8–5.8。**做鳗鲡项目时苗种单价是第一敏感因子**，必须按品种与当年行情覆盖。

> **⚠ 关于成本验证**：鳗鲡的**工艺参数**（密度/规格/换水/周期/苗价）有国际 RAS 产业数据支撑；
> 但**成本绝对值无可用外部对标** —— 国内上市公司出池量中自用转加工占比高（2026 Q1 为 86%），
> 营收÷产量反推失真；欧洲 Nijvis、ALBE 等均为私营不披露；FAO 各国成本数据过时约二十年，
> 且丹麦鳗鱼产量已由 2020 年萎缩至 2024 年的 101 吨（年均降 37%）。
> 方向性旁证：本模型算出「养美洲鳗略亏」（103.0 vs 3P 批发价 92），与 2025 年行业低谷、
> 龙头企业全年亏损 1.79 亿元同号。

**⚠ NH3-N 告警** — 鳗鲡 12.3 μg/L 接近安全上限,因其 tempOpt 28°C + 高 pH 使非离子氨占比升高。
